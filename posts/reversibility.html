The Faster You Move, the More Reversible You Need to Become

Notebook · a developing idea

AI increases the speed at which an organisation can generate options, build software, run experiments, and create change. The usual response to that kind of acceleration is to ask for more certainty before acting. That instinct becomes a problem exactly when it seems most reasonable.

Demanding more certainty takes time — and time is the one thing that gets scarcer as everything else speeds up. The alternative isn't recklessness. It's making changes smaller, outcomes more observable, assumptions more explicit, and decisions easier to reverse if they turn out to be wrong.

The underlying idea, still rough: the faster an organisation wants to move, the more reversible it needs to become. Speed and certainty were never really a package deal. Speed and reversibility might be.

I'm not sure yet what this looks like in practice for most organisations — that's the part worth exploring next.
